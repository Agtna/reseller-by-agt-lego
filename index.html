🧪 QA Testing Lab & Defect Console

Mode Defect (Bug):
AKTIF (4 Defect Sengaja Berlaku)
Nyalakan untuk uji FAIL, matikan untuk demonstrasi Regression (PASS).
1. Boundary Value Analysis (BVA) - BUG-01 BVA (REQ-01)
Spesifikasi: Pembelian jumlah LEGO per transaksi diizinkan 1 s.d. 10 unit (Min: 1, Max: 10). Nilai batas atas 11 harus DITOLAK.
Defect / Bug: Operator validasi batas atas menggunakan qty <= 11.
Cara Menguji di Web: Klik salah satu produk LEGO, buka detailnya, masukkan jumlah 11 lalu klik Tambah ke Keranjang. Sistem cacat akan menerimanya! (Expected: Ditolak).
❌ Cacat: if (qty >= 1 && qty <= 11) // Menerima 11 unit
✅ Benar: if (qty >= 1 && qty <= 10) // Maksimal 10 unit
2. Equivalence Partitioning (EP) - BUG-02 EP (REQ-02)
Spesifikasi: Partisi Valid adalah bilangan bulat positif [1..10]. Partisi Tidak Valid mencakup bilangan negatif (qty < 0). Subtotal dilarang minus dan input negatif wajib ditolak.
Defect / Bug: Perhitungan subtotal dan input manual di keranjang belanja tidak memvalidasi partisi negatif.
Cara Menguji di Web: Tambahkan item ke keranjang belanja, lalu pada kotak jumlah, ketik angka -1. Subtotal akan menjadi negatif dan mengurangi tagihan total! (Expected: Muncul error / ValueError).
❌ Cacat: subtotal = price * qty; // Mengizinkan qty = -1
✅ Benar: if (qty <= 0) throw new ValueError("Kuantitas tidak valid");
3. Decision Table Testing - BUG-03 Decision Table (REQ-03)
Spesifikasi: Kupon RESELLER10 (diskon 10%) HANYA berlaku jika:
(1) User Login Member, (2) Subtotal >= Rp 100.000, (3) Kode 'RESELLER10'.
Defect / Bug: Evaluasi kupon lupa mengecek status isLoggedIn.
Cara Menguji di Web: Pastikan status Anda adalah Tamu (Belum Login), belanja set di atas Rp 100.000, buka keranjang dan terapkan kupon RESELLER10. Tamu berhasil dapat diskon (Melanggar Rule 4 Decision Table)!
❌ Cacat: if (subtotal >= 100000 && code === 'RESELLER10') // Status login diabaikan
✅ Benar: if (isLoggedIn && subtotal >= 100000 && code === 'RESELLER10')
4. State Transition Testing - BUG-04 State Transition (REQ-04)
Spesifikasi: Transisi status pesanan dari PENDING_PAYMENT → DIPROSES_DIKIRIM → SELESAI. Transisi Terlarang: Pesanan yang sudah berstatus DIPROSES_DIKIRIM DILARANG dibatalkan langsung (DIBATALKAN) karena paket sudah di tangan kurir ekspedisi.
Defect / Bug: Tombol 'Batalkan' tetap diizinkan saat pesanan berstatus DIPROSES_DIKIRIM.
Cara Menguji di Web: Lihat pesanan AGT-ORD-9018 (status: Diproses & Dikirim) pada Riwayat Pesanan, lalu klik tombol ⚠️ Batalkan (Uji Bug). Status berhasil berubah jadi Dibatalkan (Transisi Ilegal)!
❌ Cacat: if (action === 'BATALKAN') return 'DIBATALKAN'; // Tanpa cek status
✅ Benar: if (currentStatus === 'DIPROSES_DIKIRIM') rejectTransition();
